SearaBoom

Run this command in a terminal to download the TUI and flash SearaBoom boxes.

Plug boxes in over USB. The TUI finds them. F flashes the box that's in now. Space ARMs a batch, then every box you plug in gets flashed.

Linux x86_64

curl -fsSL -o searaboom-factory-flasher-linux-amd64 https://searaboom.goossen.dev/api/factory/flasher/linux-amd64 && chmod +x searaboom-factory-flasher-linux-amd64 && ./searaboom-factory-flasher-linux-amd64
